# Security Policy

## Supported Versions

Only the latest major version receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/toruproject/mapnetwork-mcp/security/advisories/new).
This opens a private advisory visible only to the maintainer and you, so the
issue is not disclosed publicly before a fix is available.

Do not report security vulnerabilities through public GitHub issues.

We aim to respond as quickly as possible on a best-effort basis; we do not
currently commit to a fixed response-time SLA.
